# LAB 3: Practice Tasks Set

## Files

- `classes_tasks.py` contains the StringHandler, Shape, Square, Rectangle, Point, and Account tasks.
- `functions_tasks.py` contains the conversion, puzzle, prime, string, list, and histogram tasks.
- `guess_number.py` contains the interactive guess-the-number game.
- `movie_tasks.py` contains the movie dictionary tasks.
- `use_functions.py` imports and uses functions from `functions_tasks.py`.

Run any non-interactive file from this directory. For example:

```powershell
cd Practice3/Practice-Tasks-Set
python use_functions.py
```
