# Practice 3: Functions and Object-Oriented Programming

This practice contains simple, runnable examples of Python functions, lambda expressions, classes, and inheritance.

## Structure

- `functions/` covers basic functions, arguments, return values, `*args`, and `**kwargs`.
- `lambda/` covers basic lambdas with `map()`, `filter()`, and `sorted()`.
- `classes/` covers class creation, constructors, instance methods, and class variables.
- `inheritance/` covers inheritance, `super()`, method overriding, and multiple inheritance.

## Run an example

```powershell
python Practice-03/functions/basic_functions.py
```

Each file is independent and prints its result when run.
