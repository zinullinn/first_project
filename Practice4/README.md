# Practice 4: Python Advanced Topics

Runnable exercises for iterators and generators, dates and time, math and random, and JSON.

## Files

- `exercices/generators.py` — iterator protocol, custom iterator, generator function, and generator expression.
- `exercices/dates.py` — date creation/formatting, elapsed time, and timezone conversion.
- `exercices/math.py` — built-in math operations, `math` functions, and random helpers.
- `exercices/json.py` — parsing, serialization, and reading/writing `sample-data.json`.
- `exercices/sample-data.json` — data used by the JSON exercises.

Run from the repository root with `python Practice4/exercices/<filename>.py`.

The date and random examples use deterministic sample values where practical so their output is easy to follow.
